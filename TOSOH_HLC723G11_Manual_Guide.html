1. Overview - Power Switch Operation

Main Power Switch

The main power switch is located to activate the power of the device. The switch is labeled "I" for powering on the device and "O" for powering off the device.

Operation Status

After pressing the Power key on the front panel, the machine displays the HbA1c / STD ANALYSIS operation status. The display shows the operation status of the analyzer that has been set.

Device Statuses

The following statuses are displayed when operating the analyzer:

  • WARMING-UP: Device initialization phase
  • STAND-BY: Device ready, awaiting sample input
  • ANALYSIS: Currently analyzing samples
  • WASH: Column washing after sample analysis
  • COL.WASH: Column wash for reagent change
  • BUFF PRIME: Buffer priming operation
  • PUMP WASH: Pump cleaning and washing
  • PURGING: System purging operation

2.1 Daily Care

Before pressing the Power key, ensure the following checks are completed:

Check Elution Buffers and Wash Solution

Verify that Elution Buffers 1, 2, 3 and Hemolysis & Wash Solution levels are adequate. These should be checked to ensure proper operation of the analyzer.

Reagent Replacement

Reagent kit 1 contains materials for approximately 270 runs. When the reagent level drops below the minimum mark, replacement is necessary. Refer to Section 5 for reagent replacement procedures.

Paper Replacement

Ensure printer paper is available. When depleted, paper replacement is needed. Refer to Section 6 for paper replacement procedures.

Dilution Port Maintenance

The dilution port should be kept clean and clear. Ensure the port opening is free of debris and properly positioned for accurate sample dilution during analysis.

Important: Always dispose of waste contaminated with blood as biohazard waste according to standard operating procedures.

2.2 Powering On - Warming Up

Startup Process

  1. Press the Power key on the front panel display
  2. The device will enter WARMING-UP phase
  3. During warm-up, the following operations occur:
    • PUMP CLEAN: Pump line cleaning
    • BUFF PRIME: Buffer priming (approximately 5 mL per buffer)
    • WARMING-UP: Temperature stabilization
    • STAND-BY: Sampling line priming

Warm-up Duration

The warm-up phase requires approximately 8 minutes. The machine will automatically transition to STAND-BY status when initialization is complete.

Number of Injections

The system tracks the number of filter and column injections. Monitor these counts during the warm-up phase on the main display screen.

Solenoid Valve Status

The solenoid valve operations are controlled during warm-up. Verify proper valve function by observing the display indicators.

2.3 Preparation Sample

Sample Types

Samples should be prepared as follows:

Patient Sample (Whole Blood)

  • Use whole blood samples
  • Volume should be adequate (>1 mL recommended)
  • Mix by inverting in sample rack

Calibrator or Control

  • Prepare calibrator material as specified in package insert
  • Transfer into sample cup
  • Place in designated positions in rack

Sample Dilution

If the sample requires pre-dilution:

  • Dilute sample with Hemolysis & Wash Solution
  • Total area should be 700-3000 for acceptable results
  • If Total area is below 700, dilute 1:100
  • If Total area is above 3000, dilute 1:400

Sample Preparation Notes

Primary tube must be mixed thoroughly before analysis. For diluted samples, use the cup adapter. Pipette approximately 150 µL into the sample cup.

2.4 Load Sample

Sample Rack Types

The analyzer accepts two types of sample racks:

  • TOSOH Rack: Holds sample vials using sample adapter
  • SYSMEX Rack: Alternative rack type with barcode capability

Sample Rack Loading Procedure

For TOSOH Rack with primary tubes:

  • Use sample vial with adapter or cup adapter
  • Insert positions numbered 1-10 in the rack
  • Position 10 should contain End Marker or empty rack
  • Sampling needle will aspirate from each position

Cup Adapter

Use the cup adapter for diluted samples. The cup adapter connects to the sampling needle in the defined rack position.

Rack Position Assignment

Control samples should be placed in Rack Position 1 (position code 1). Positions 1-2 typically contain calibrators and controls. Positions 3 onwards contain patient samples.

Sample Rack Loading Location

Load the sample rack into the Rack position marked on the analyzer front panel (marked as position A). Ensure the rack is properly seated.

2.5 Processing Patient Samples

Starting Analysis

  1. Load sample racks into positions as described in Section 2.4
  2. Place the End Marker or empty rack at position 10 to signal analysis completion
  3. Press the START key on the front panel

Analysis Process

After pressing START, the analyzer will:

  • Perform calibration check if CALIB key is enabled
  • Begin ANALYSIS phase
  • First result will be obtained approximately 2 minutes after START
  • Subsequent results will be obtained at approximately 1-minute intervals

Automated Dilution

The machine automatically dilutes samples at 1:201 ratio. For samples requiring different dilutions, enter dilution mode before analysis.

End of Analysis

When the End Marker is detected or empty rack position is reached, the analyzer will:

  • Perform WASH cycle
  • Return to STAND-BY status
  • Complete PUMP WASH operation

Shutdown Sequence

If not performing additional analysis, the analyzer will proceed to Shut-Off after 2 cycles of standby. Parameter settings can be used to customize the Off-timer (1, 2, or 3 hours).

2.6 Interpretation of Test Result

Result Report Components

The printed result includes:

  • Sample Number/Rack Number: Identifies the sample position
  • HbA1c Value: The primary result expressed as percentage
  • Sample ID: Barcode identification if available
  • Calibration Factor: Linear equation parameters (Y = Slope × + Intercept)
  • Total Area: Quality indicator showing integration value
  • Hemoglobin Fractions: Peak breakdown showing component percentages
  • Chromatogram: Visual peak pattern display
  • Flag Messages: Any quality warnings or errors

Peak Components

The report displays hemoglobin fraction results including:

  • FP (Front Peak)
  • A1A, A1B (HbA1c variants)
  • A1C (Main HbA1c peak)
  • F (HbF)
  • A0 (Other hemoglobins)

Total Area Significance

Total area represents the integrated chromatography peak area. Acceptable range is 700-3000. If outside this range, the sample may require re-analysis with appropriate dilution.

Flag Messages Interpretation

Flag messages appearing on the result indicate:

  • AREA HIGH / AREA TOO HIGH: Total area exceeds 3000 (consider dilution)
  • AREA LOW / AREA TOO LOW: Total area less than 700 (consider higher concentration or different dilution)

2.7 Calibration (Preparation) & 2.8 Calibration (Assay)

Calibration Preparation

  1. Obtain calibrator kit from package (contains 4 mL bottle, approximately 1 bottle calibrator)
  2. Pipette calibrator approximately 400 µL into sample cup
  3. Transfer into cup adapter

Calibrator Loading

  1. Load calibrator rack at Position A on the analyzer
  2. Ensure calibrators are in Rack position 1 (positions 1 and 2 for Low and High)
  3. Verify rack is properly seated

Calibration Assay Procedure

  1. Determine Calibrate on main menu screen
  2. Press CALIB key (Calibrate or STD button)
  3. Set CALIB parameter using the calibration entry
  4. Press CALIB SET button

Calibration Process

After pressing START key:

  • Machine performs 5 total injections (3 of Calibrator 1, 2 of Calibrator 2)
  • Calibration takes approximately 8 minutes
  • Results show calibrator values and calibration equation

Calibration Report

Upon completion, a Calibration Report is printed showing:

  • Calibration date and time
  • OLD calibration equation (previous)
  • NEW calibration equation (current)
  • Filter count and column count

Calibration Acceptance

The calibration will show status as COMPLETED or indicate a Calibration Error. Check that calibrator values are within acceptable limits before proceeding with patient sample analysis.

Control Validation

After calibration, controls should be analyzed to verify system performance before running patient samples.

2.9 Priority (STAT) Assay

STAT Sample Definition

STAT (Priority) samples are analyzed using the alternative port located on the analyzer. This allows for priority analysis separate from the routine sample queue.

STAT Port Location

The STAT port is positioned on the right side of the analyzer at mid-height. A dedicated sampling needle is available for STAT port operation.

STAT Sample Types

STAT samples can be prepared as:

  • Whole blood samples (primary tube or sample cup)
  • Pre-diluted samples using cup adapter
  • Diluted at 1:200 or other ratios as needed

STAT Sample Preparation

  1. Prepare sample as whole blood or diluted specimen
  2. Sample should be >1 mL for whole blood or >150 µL for pre-diluted
  3. Select STAT mode on analyzer screen

STAT Sample Loading

  1. On STAT Screen, enter Sample ID if available
  2. Select BLOOD for whole blood or DILUTED for pre-diluted
  3. Open STAT port cap
  4. Insert sample vial or cup adapter into STAT port
  5. Sample needle will automatically aspirate approximately 5 µL
  6. Remove sample after needle retracts
  7. Close STAT port cap immediately

STAT Analysis

After sample insertion and port closure:

  1. Press START key from STAT screen
  2. Machine will pause routine analysis if running
  3. STAT sample analysis proceeds immediately
  4. Result will be available in 2-3 minutes

Auto-Resume Function

After STAT result is complete:

  • Machine performs WASH cycle
  • Routine sample analysis automatically resumes
  • STAT result is clearly marked with 8000-series sample number

Special Dilution Modes for STAT

STAT mode allows selection of dilution levels:

  • DEFAULT (1:201): Standard dilution for normal hematocrit
  • INCREASE (1:100): For low hematocrit samples
  • DECREASE (1:400): For high hematocrit samples

3-6 Maintenance Procedures

Filter Replacement (Section 3)

Filter replacement is performed when samples run exceeds approximately 600 samples or when pump pressure increases above 2 MPa.

Procedure:

  1. Open the right door of the incubator
  2. Rotate the Filter handle counter-clockwise
  3. Remove the old filter element
  4. Insert new filter with ribbed edge facing upward
  5. Rotate Filter handle clockwise to lock
  6. Close incubator door
  7. Verify pressure reading (should read 6+ MPa)

Column Replacement (Section 4)

Column replacement is required after approximately 2500 runs or when chromatograms show baseline issues or unknown peaks.

Procedure:

  1. Cool column to room temperature
  2. Open incubator door
  3. Disconnect pump inlet (right side connection only)
  4. Remove protective plugs from new column
  5. Connect new column pump inlet
  6. Prime buffer through new column (observe left outlet)
  7. Connect detector inlet (left side)
  8. Close incubator door
  9. Verify pressure is within specification

Reagent Replacement (Section 5)

Elution Buffers and Hemolysis/Wash Solution replacement procedure:

Procedure:

  1. Navigate to REAGENT CHANGE menu
  2. Press REAGENT CHANGE button (when highlighted on MAINTE screen)
  3. Highlight reagents requiring replacement (turns green when selected)
  4. Remove old bottles from aluminum holders
  5. Install new reagent bottles with correct color-coded tubing
  6. Press PRIME button to prime new reagents into system
  7. Observe progress bar filling to 100%
  8. Press OK to confirm reagent installation

Reagent Notes:

  • Elution Buffer Lot must match Column Lot
  • Never mix reagent lots from different shipments
  • Hemolysis & Wash Solution must be replaced when depleted (do not reuse)

Printer Paper Replacement (Section 6)

Printer paper replacement occurs after approximately 270 runs.

Procedure:

  1. Open printer cover
  2. Remove spent paper roll
  3. Insert new thermal paper roll onto mandrel
  4. Advance paper through feed slot
  5. Verify alignment in exit slot
  6. Close printer cover

7-9 Troubleshooting, Results Retrieval & Abnormal Chromatograms

Section 7: Recalculation (Reprinting/Transmission Results)

Results stored in analyzer memory can be recalled, reprinted, or transmitted to host systems. Last 800 results are retained in system memory.

Retrieval Procedure:

  1. Press MENU button on main screen
  2. Select RESULT or LIST option
  3. Use SEARCH to locate results by date
  4. Filter by CAL (Calibration), CTL (Control), or SP. (Sample)
  5. Select sample range or specific result
  6. Press command button: PRINT / TRANS (transmit) / DELETE

Section 8: Trouble Shooting

AREA HIGH (Area Too High) - Flag Message

Occurs when Total area exceeds 3000 (approximately 4000 limit). This indicates high hemoglobin concentration and low hematocrit. Solution: Dilute sample at 1:400 using STAT mode (50 µL blood + 2 mL solution).

AREA LOW (Area Too Low) - Flag Message

Occurs when Total area is below 500-700. This indicates low hemoglobin concentration. Solution: Dilute sample at 1:100 using STAT mode (50 µL blood + 5 mL solution) or check sample for proper preparation.

100 PRESSURE HIGH Error

Pump pressure exceeds safe threshold. Causes include: clogged filter, deteriorating column, or air in pump. Solutions: Check and replace filter if >600 samples, replace column if >2500 samples, or run system purge/drain flush procedure.

101 PRESSURE LOW Error

Pump pressure drops below expected level. Causes include: air in pump, empty buffer bottle, check valve failure. Solutions: Verify buffer bottles are not empty, run DRAIN FLUSH procedure (see Appendix-3), check tubing connections.

201 CALIB ERROR

Calibration values fall outside acceptable limits. Solutions: Verify calibrator values match package insert, check that calibrator lot matches column lot, verify reagent is not expired, replace Elution Buffers, or replace column if suspect.

Section 9: Abnormal Chromatograms

Abnormal chromatograms show unexpected peak patterns. May indicate hemoglobin variants (Hb S, Hb C) or system issues. Compare against normal chromatogram patterns showing 5 distinct hemoglobin peaks.

Potential Causes:

  • Hemoglobin variant in patient sample
  • Column deterioration
  • Pump flow issues
  • Reagent problems
